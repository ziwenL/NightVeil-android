# 夜幕视觉规范

统一主题：深夜蓝与柔和月光色。主页、通知调节面板、定时选择框、图标和状态样式共用资源。

## 颜色与层级

- 页面底色：`#0C121C`；卡片：`#172230`；次级控件：`#202E3E`。
- 月光强调色：`#DCCBAD`，用于主要操作、滑块和选中状态。
- 正文：`#ECEAE4`；辅助信息：`#A3AFBF`；边线：`#2A3849`。
- 关闭遮罩属于运行中的操作，使用次级底色与清晰文字；开启按钮使用强调色。

## 组件

- 卡片与面板圆角 28dp；主要按钮 20dp；次级按钮 16dp；预设 14dp。
- 交互区域至少 48dp。滑块保留逐级调节，隐藏密集刻度与浮动标签。
- 预设和定时选项都明确标示选中状态；定时选择另外提供勾选图标。
- 眼罩、月牙和星光作为统一图形，搭配细线时钟、电源、太阳和月亮图标。

## 页面

- 竖屏：品牌 → 调节卡片 → 系统快捷操作 → 权限及使用提示。
- 横屏：左侧品牌、开关和定时；右侧强度、滑块与预设。较大字体时允许页面滚动。
- 通知调节面板沿用主页控件；定时弹窗使用相同卡片、颜色及选中状态。
- 系统通知和快捷磁贴的外框与状态颜色由系统控制，应用提供统一的单色图标。

## 验证

- 构建、33 项单元测试、静态检查通过。
- 已在 2211133C 上保留数据安装；检查竖屏、横屏双栏和较大字体，检查后恢复原有显示设置。
- 已在 Android 11 测试手机上检查通知调节面板与定时弹窗。
