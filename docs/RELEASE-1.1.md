# 夜幕 1.1

- 全 App 统一为深夜蓝与月光色，重做主页、通知调节面板和定时选项，新增横屏双栏布局。视觉规范见 `UI_STYLE.md`。

- 主页和通知调节面板标明“更亮 / 更暗”，向右拖动增加遮罩强度。
- 定时关闭支持不限时、15、30、60 分钟。未开启遮罩时可预选；运行中选择会从当前时刻重新计时。选择不限时可取消计时，关闭遮罩也会清除本次计时；下次开启仍记住选择的时长。
- 主页、调节面板和通知显示计时状态。手机休眠、省电或系统调度可能使自动关闭延迟，因此显示为约定时间，无需额外申请精确闹钟权限。
- Android 7.0 及以上提供“夜幕”系统快捷设置磁贴。Android 13 及以上可从主页发起添加，旧系统提供手动添加指引。长按磁贴打开主页。
- 遮罩继续铺满屏幕；Android 12 及以上使用窗口透明度，强度上限为 80%，以保留对下层应用的触摸操作。旧系统最高 90%。
- 通知保留直接关闭操作，停止后的滞后滑块事件不会重新启动遮罩。
- 快捷磁贴改用“眼罩、月牙与星光”的单色图标，声明为可切换开关，并监听运行状态实时更新高亮。合并部分控制中心在 350 毫秒内重复派发的点击，避免关闭后被紧接着重新开启。

夜幕通过黑色遮罩进一步调暗显示，不改变系统背光设置。
